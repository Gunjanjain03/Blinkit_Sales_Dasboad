# 🛒 Blinkit Sales Dashboard

This Power BI dashboard provides a concise analysis of Blinkit's sales data.

## 📌 Overview

- Visualizes total sales, average sales, number of items, and average ratings.
- Filters available for outlet location type, size, and item type.
- Breakdown of sales by:
  - Item type
  - Fat content
  - Outlet size, type, and location
- Outlet establishment trend from 2010 onwards.

## 📊 Key Metrics

- **Total Sales**: $1.2M  
- **Avg Sales**: $141  
- **No. of Items**: 8523  
- **Avg Rating**: 3.9

## 🛠 Tools Used

- Power BI
- DAX for calculated measures
- Excel/CSV (assumed source data)
